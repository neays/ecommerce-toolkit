# Ecommerce Toolkit

Herramientas gratuitas y de código abierto para que pequeños comercios digitales estimen rentabilidad por pedido, resultados de contraentrega y métricas básicas de publicidad.

## Funciones

- Calculadora de rentabilidad por pedido.
- Estimación de tasa de entrega y costo de pedidos no entregados.
- Costo por conversación, costo por adquisición (CPA) y ROAS estimado.
- Cálculos locales en el navegador: no se envían datos a un servidor.

## Cómo usar

1. Descarga o clona este repositorio.
2. Abre `index.html` en un navegador moderno.
3. Cambia los valores de ejemplo por tus cifras.

No requiere instalación, dependencias ni claves API.

## Publicar gratis con GitHub Pages

1. Crea un repositorio público en GitHub llamado `ecommerce-toolkit`.
2. Sube todos los archivos y carpetas de este proyecto conservando su estructura.
3. En el repositorio, abre **Settings → Pages**.
4. En **Build and deployment**, selecciona **Deploy from a branch**.
5. Selecciona la rama `main` y la carpeta `/ (root)`, y guarda.
6. GitHub Pages publicará el sitio en unos minutos. La URL tendrá el formato `https://neays.github.io/ecommerce-toolkit/`.

## Contribuir

Las contribuciones son bienvenidas. Abre un issue para reportar errores o proponer mejoras y envía un pull request con una descripción clara de los cambios.

Antes de enviar código:
- Prueba los cálculos con valores conocidos.
- Mantén la interfaz accesible y adaptable a móviles.
- No agregues servicios de terceros que transmitan los datos ingresados sin explicar claramente su uso.

## Alcance y limitaciones

Esta herramienta ofrece estimaciones educativas. No se conecta a Shopify, Meta Ads, pasarelas de pago ni transportadoras. El usuario debe ingresar sus propios datos. No constituye asesoría contable, financiera ni una garantía de rentabilidad.
